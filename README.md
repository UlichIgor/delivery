Feast Sushi

Feast Sushi — сучасний вебзастосунок для служби доставки суші, розроблений як односторінковий застосунок (SPA) з акцентом на швидкість, зручність користування та адаптивний інтерфейс.

Проєкт дозволяє користувачам переглядати каталог страв, шукати товари, фільтрувати меню за категоріями, додавати позиції до кошика та оформлювати замовлення. Для покращення взаємодії з клієнтами реалізовано систему відгуків, сторінку доставки та контактну інформацію.

Основні можливості
Каталог суші, ролів, поке, салатів, супів та напоїв.
Пошук товарів за назвою та описом.
Фільтрація за категоріями.
Кошик покупок із збереженням даних між сесіями.
Форма надсилання відгуків.
Адаптивний дизайн для мобільних пристроїв і ПК.
Інтеграція з базою даних для зберігання замовлень та відгуків.

Моя роль

Самостійно розробив архітектуру застосунку, реалізував клієнтську частину, налаштував маршрутизацію, інтеграцію з базою даних, систему кошика та адаптивний інтерфейс. Особливу увагу приділив продуктивності, зручності користування та масштабованості проєкту.

Результат

Створено повноцінний вебзастосунок доставки суші з сучасним UX/UI, який демонструє навички розробки frontend-рішень, роботи з React-екосистемою та інтеграції з хмарними сервісами.
