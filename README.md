# Feast Sushi

Feast Sushi — вебзастосунок ресторану, у якому можна переглянути каталог страв, відфільтрувати його за категоріями та зібрати кошик. Цей файл пояснює, як користуватися наявними можливостями сайту, які розділи доступні та які функції ще перебувають у планах розробки.

## Як користуватися сайтом

### Перегляд меню

На сторінці відображається список страв із назвою, описом, зображенням і ціною. За допомогою кнопок категорій над списком можна показати все меню або вибрати одну з категорій: сети, роли, поке й салати, паста та локшина, рибні страви, супи чи напої. Щоб повернутися до повного списку, виберіть категорію «Усе».

### Додавання страв до кошика

Натисніть кнопку «+» біля страви, щоб додати її до кошика. Значок кошика у верхній частині сторінки показує кількість різних позицій у ньому. Якщо додати ту саму страву ще раз, її кількість збільшиться.

Натисніть значок кошика, щоб переглянути вибрані страви. У кошику кнопки «+» і «−» змінюють кількість одиниць; кількість не може бути меншою за одну. Піктограма видалення прибирає позицію з кошика. Загальна сума оновлюється відповідно до складу замовлення.

## Розділи сайту

У верхній навігації доступні такі розділи:

- **Головна** — початкова сторінка з рекламним банером і пропозиціями.
- **Про нас** — сторінка з назвою розділу; інформаційний текст про ресторан у поточній версії ще не доданий.
- **Зона доставки** — сторінка-заголовок. Адреси, мапа та умови доставки ще не відображаються.
- **Залишити відгук** — розділ для майбутнього сценарію відгуків; форма надсилання наразі відсутня.
- **Контакти** — сторінка-заголовок без контактної інформації. Номер телефону в шапці сайту можна натиснути, щоб відкрити дзвінок на пристрої, який підтримує телефонні посилання.

Каталог і фільтр категорій відображаються незалежно від вибраного розділу. Навігація між сторінками відбувається без повного перезавантаження сайту.

## Що варто знати про поточну версію

- Каталог меню та ціни зберігаються безпосередньо в коді застосунку. Серверного API або бази даних проєкт наразі не використовує.
- Кошик працює лише в межах поточного сеансу сторінки: після перезавантаження браузера його вміст не зберігається.
- Кнопка «Купити» відображається в кошику, але надсилання замовлення, оплата та підтвердження покупки ще не підключені.
- Вміст сторінок «Про нас», «Зона доставки», «Залишити відгук» і «Контакти» поки що обмежений заголовками або навігаційним посиланням.

Отже, сайт дає змогу ознайомитися з меню та сформувати кошик, але не оформити й не оплатити реальне замовлення.

## Плани подальшої розробки

Можливі наступні кроки розвитку Feast Sushi:

1. Підключити серверний API та базу даних для керування меню, описами й цінами без зміни коду клієнтської частини.
2. Реалізувати оформлення замовлення: контактні дані, адресу доставки, перевірку введеної інформації та передавання замовлення на сервер.
3. Додати збереження кошика між відвідуваннями, а за наявності облікових записів — синхронізацію з сервером.
4. Створити облікові записи клієнтів, історію покупок і перегляд статусу замовлення.
5. Додати адміністративний інтерфейс для керування стравами, цінами та замовленнями.
6. Заповнити інформаційні сторінки відомостями про ресторан, контактами, відгуками та актуальними зонами доставки.
7. Розробити й перевірити автоматизованими тестами основні сценарії: фільтрацію меню та керування кошиком.

Це можливі напрями розвитку, а не функції, доступні в поточній версії.

## Технології та структура

Застосунок побудований як односторінковий сайт (SPA) на React. Основна логіка меню, фільтра категорій і кошика розташована в `src/App.jsx`. Маршрути між розділами налаштовані через React Router із `HashRouter`. Спільні частини інтерфейсу — шапка, картки меню, категорії, кошик і нижня частина сайту — винесені в `src/components/`, а сторінки розділів — у `src/pages/`.

Інтерфейс стилізовано за допомогою SCSS. Webpack і Babel використовуються для підготовки застосунку до розробки та публікації. Статичні ресурси розташовані в `public/` і `src/images/`, а production-збірка створюється в каталозі `build/`.

Основні технології:

- React і JavaScript (JSX) — інтерфейс і логіка застосунку.
- React Router — навігація між сторінками.
- SCSS — стилі.
- React Bootstrap і React Icons — компоненти інтерфейсу та іконки.
- Webpack і Babel — обробка та збірка файлів.

## Запуск проєкту

Для локального запуску потрібні встановлені Node.js та npm. У терміналі перейдіть до каталогу проєкту й виконайте:

```bash
npm install
npm start
```

Перша команда встановить залежності, друга запустить режим розробки. Після запуску відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

## Збірка та публікація

Щоб перевірити production-збірку, виконайте:

```bash
npm run build
```

Готові файли буде створено в каталозі `build/`. Для публікації на GitHub Pages у проєкті налаштована команда:

```bash
npm run deploy
```

Вона спочатку створює production-збірку, а потім публікує каталог `build/` у гілці `gh-pages`. Для публікації потрібні відповідні права доступу до репозиторію та налаштування GitHub Pages.
