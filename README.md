# 🍣 Feast Sushi — технічний опис сторінки

## 🔑 Загальна інформація
- **Тип сторінки:** веб‑сайт ресторану японської кухні.  
- **Призначення:** представлення меню, контактів, зони доставки та можливість додати страви в кошик.  
- **Цільова аудиторія:** користувачі, які замовляють суші та інші страви онлайн.  

## ⚙️ Технології та інструменти
- **Frontend:** HTML5, CSS3/SCSS, JavaScript (ES6+).  
- **Backend:** локальний сервер (http://localhost), можливе використання Node.js для тестування.  
- **Редактор:** Visual Studio Code.  
- **Система контролю версій:** GitHub.  

## 📦 Структура сторінки
- **Головна навігація:** розділи “Про нас”, “Зона доставки”, “Залишити відгук”, “Контакти”.  
- **Меню:** категорії страв — сети ролів, окремі роли, поке та салати, паста/локшина, рибні страви, супи, напої.  
- **Товари:** кожна позиція має назву, склад, ціну та кнопку “Добавити в кошик”.  
- **Контакти:** телефон +38 (068) 874‑47‑34, посилання на соцмережі.  
- **Футер:** © sushi 2023, автор Ulich Igor.  

## 🔍 Особливості реалізації
- **Адаптивність:** оптимізація для мобільних пристроїв.  
- **UI/UX:** просте меню з цінами, акцент на візуальну подачу страв.  
- **Модульність:** кожна категорія меню реалізована як окремий компонент.  
- **Функціонал:** інтерактивний кошик для додавання страв.  
- **Можливості розширення:** інтеграція онлайн‑замовлення, системи оплати, відстеження доставки.
