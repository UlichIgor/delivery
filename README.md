# 🍣 Feast Sushi — технічний опис

## 🔑 Загальна інформація
- **Тип проєкту:** веб‑сайт ресторану японської кухні.  
- **Призначення:** представлення меню, контактів та інформації про доставку.  
- **Цільова аудиторія:** клієнти, які замовляють суші та інші страви онлайн.  

## ⚙️ Технології
- **Frontend:** HTML5, CSS3/SCSS, JavaScript (ES6+).  
- **Backend:** Node.js (локальний сервер для тестування).  
- **Середовище розробки:** Visual Studio Code.  
- **Система контролю версій:** GitHub.  

## 📦 Структура проєкту
- **Головна сторінка:** вітальний екран із меню.  
- **Меню:** категорії (сети ролів, окремі роли, рибні страви, супи, салати, напої).  
- **Контакти:** телефон, інформаційні розділи (“Про нас”, “Зона доставки”, “Відгуки”).  
- **Зона доставки:** інтерактивний блок для перевірки доступності доставки.  

## 🔍 Особливості реалізації
- **Адаптивний дизайн:** оптимізація для мобільних пристроїв.  
- **UI/UX:** просте меню з цінами, акцент на візуальну подачу страв.  
- **Модульність:** кожна категорія меню реалізована як окремий компонент.  
- **Можливості розширення:** інтеграція онлайн‑замовлення, кошика, системи оплати.
